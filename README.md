# partial-things

A partial Things-style to-do app. Not Things, and not finished.

PHP and SQLite. Lists, dates, projects, headings, checklists, tags, reminders, and a rough Quick Find.

```sh
php -S 127.0.0.1:8787 -t public public/router.php
```

Needs PHP with `pdo_sqlite`. Open http://127.0.0.1:8787/

Apple emoji names come from [react-apple-emojis](https://github.com/dherault/react-apple-emojis) (MIT). The images load from that project's CDN.
